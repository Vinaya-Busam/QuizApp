### 📖 About The Project

**Quiz App** is a full-stack web application designed to provide an interactive platform for conducting and managing online quizzes.

The application provides separate experiences for **Users** and **Administrators**.

**Users** can register, authenticate securely, browse quizzes, take timed assessments, submit answers, view results, and track their previous attempts.

**Administrators** have access to a dedicated dashboard where they can manage users, quizzes, categories, and questions through protected CRUD operations.

---

### 🛠️ Tech Stack

**Frontend:** React.js, JavaScript, HTML5, CSS3, Axios, React Router

**Backend:** Java, Spring Boot, Spring Security, JWT, Spring Data JPA, Hibernate

**Database:** MySQL

**API:** RESTful APIs, Swagger / OpenAPI

**DevOps:** Docker, Docker Compose

**Tools:** Git, GitHub, GitHub Codespaces, Maven

### ✨ Key Features

| Feature | Description |
|---|---|
| 🔐 JWT Authentication | Secure authentication using JSON Web Tokens |
| 👥 Role-Based Access | Separate User and Admin functionality |
| 📝 User Registration | Users can create their own accounts |
| 📚 Quiz Management | Admins can create, update, view and delete quizzes |
| ❓ Question Management | Admins can manage quiz questions |
| 🗂️ Category Management | Admins can manage quiz categories |
| ⏱️ Timed Quizzes | Configurable time limit for every quiz |
| 🚀 Auto Submission | Quiz automatically submits when the timer expires |
| 📊 Result Analysis | Users can view scores and percentages |
| 📈 Performance Dashboard | Users can track quiz performance |
| 🕒 Attempt History | Users can view previous quiz attempts |
| 📄 Pagination | Paginated user management |
| 🔒 Answer Protection | Correct answers are not exposed to users |
| 📖 Swagger | Interactive API documentation |
| 🐳 Docker | Containerized MySQL development environment |
| 📱 Responsive UI | Frontend adapts to different screen sizes |
